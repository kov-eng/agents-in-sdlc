使用真实场景、完整应用程序和共享待办事项来探索 GitHub Copilot 在软件开发生命周期中的应用。你将迭代地规划变更、创建代码、测试行为、审查 pull request，并使用代理管理工作。

## 场景

你是一名 Tailspin Toys 的新开发者，Tailspin Toys 是一家虚构公司，专门为具有开发者主题的桌游提供众筹。你的团队待办事项已作为 GitHub issues 归档，随时可供你接手。它包括功能开发，如筛选和分页，以及质量改进，例如无障碍和编码标准。

## 选择你的环境

GitHub Copilot 会在你工作的任何地方与你相遇。选择最符合你构建方式的环境。每个工作坊都从各自的设置开始，并使用共享的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理式助手。使用 Plan 和 Autopilot 模式、instructions、skills、自定义代理、Playwright MCP、Agent Merge，以及实用的 slash 命令。

### [GitHub Copilot app][app]

运行并行代理会话、切换会话模式、在画布上协作，并在桌面应用中管理 GitHub issues 和 pull requests。

### [GitHub Copilot cloud agent][cloud]

将 GitHub issue 分配给异步代理，指导其工作，监控进度，并审查它创建的 pull request。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 代理模式、MCP 服务器和自定义代理。
