多くの CLI ツールと同様に、GitHub Copilot CLI には対話に使うスラッシュ コマンドが多数あります。高度な機能、内部情報、追加の構成オプションを利用できます。これまで `/diff`、`/mcp`、`/skills`、`/agent`、`/pr` などのコマンドを使いました。次は、他の便利なコマンドも確認しましょう。

このレッスンでは、次のことを行います。

- `/context` と `/compact` を使って Copilot の会話コンテキストを調べます。
- `/model` で利用可能なモデルを確認します。
- `/share` でセッションをエクスポートまたは共有する方法を学びます。
- 並行作業、worktree、クラウド エージェントへの委任に使うオプションのコマンドを確認します。

## シナリオ

CLI の主要なワークフローを終えたところです。ここでは、コンテキスト管理、モデル切り替え、セッション共有、および [Copilot クラウド エージェント][about-cloud-agent]へのオプションの委任など、追加機能を確認します。

## Copilot CLI のコンテキストを確認する

大規模または複雑なタスクに取り組むと、モデルのコンテキスト ウィンドウの上限に達することがあります。Copilot CLI は必要に応じて会話を自動的に圧縮します。また、スラッシュ コマンドを使って自分で確認したり圧縮したりできます。

1. Codespace に戻り、まだ開いていない場合はリポジトリのルートから Copilot CLI を起動します。
2. 次を入力します。

   ```plaintext
   /context
   ```

3. モデル、現在のトークン使用量、システム指示、ツール、メッセージ、空き領域にコンテキストがどのように分かれているかを確認します。
4. 会話を圧縮します。

   ```plaintext
   /compact
   ```

5. もう一度 `/context` を入力し、結果を比較します。会話が小さい場合、大きな違いはないことがあります。

> [!NOTE]
> コンテキスト ウィンドウが埋まると、Copilot CLI は自動的に圧縮します。自分でタイミングを選びたい場合は `/compact` を使います。無関係な別のタスクに切り替えるために新しい会話を始めたい場合は、`/clear` または `/new` を使います。

## モデルを選ぶ

モデルごとに得意分野が異なり、開発者によって好みも異なります。Copilot CLI では、利用できるモデルを一覧表示して選択できます。

1. 次を入力します。

   ```plaintext
   /model
   ```

2. 利用可能なモデルと使用状況に関する情報を確認します。
3. 現在のモデルをそのまま使うか、別のモデルを選択するか、<kbd>Esc</kbd> を押して一覧を閉じます。

## セッションを共有する

チームとして協力し、学んだことを共有すると、AI ツールの活用方法を改善できます。`/share` コマンドは、セッションを Markdown または HTML ファイルにエクスポートしたり、共有可能なリンクを作成したり、GitHub gist を公開したりできます。

1. `/help` を入力し、インストール済みバージョンの `/share` オプションを確認します。
2. セッションを共有する場合は、`/share file` によるローカルな Markdown エクスポートなど、用途に合った出力先を選択します。
3. エクスポートした内容を、誰かに送ったり公開したりする前に確認します。セッションのエクスポートには、プロンプト、応答、プロジェクトの詳細が含まれる場合があります。

リンクや gist の公開は任意です。チームが共有するつもりのないリポジトリや会話の内容を公開しないでください。

## 任意: 作業を拡張または委任する

ワークショップの主要な部分は完了しました。Copilot CLI には、大きなタスク向けのコマンドも用意されています。

- `/fleet` は、独立したサブタスクを複数のサブエージェントに分割し、並行して実行します。
- `/worktree` は、別のタスク用に独立した Git worktree を作成します。
- `/delegate` は、Copilot クラウド エージェントにタスクを送信します。エージェントは非同期に作業し、プルリクエストを作成する場合があります。

これらのコマンドは、追加の worktree やリモートの作業を作成する場合があるため、任意です。試すときは、まず新しい会話を開始して、スコープを明確にしたタスクを依頼します。通常のワークフローに沿って結果をレビューしてください。非同期エージェントをさらに詳しく確認する場合は、[クラウド エージェントのワークショップ][cloud-workshop]に進みます。
