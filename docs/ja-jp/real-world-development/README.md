GitHub Copilot を使って、現実的なシナリオ、完全なアプリケーション、共有バックログを通じて、ソフトウェア開発ライフサイクル全体を体験してください。計画の立案、コードの作成、動作確認、プルリクエストのレビュー、エージェントによる作業管理を繰り返し進めていきます。

## シナリオ

あなたは Tailspin Toys の新しい開発者です。Tailspin Toys は、開発者向けテーマのボードゲームに対するクラウドファンディングを提供する架空の会社です。チームのバックログはすでに GitHub issue として登録されており、あなたが取り組む準備ができています。フィルタリングやページネーションのような機能開発だけでなく、アクセシビリティやコーディング標準の向上などの品質改善も含まれています。

## 環境を選択してください

GitHub Copilot は、開発の進め方に合わせてサポートします。自分の作業スタイルに合う環境を選んでください。各ワークショップは独自のセットアップから始まり、共有された Tailspin Toys のシナリオを使用します。

### [GitHub Copilot CLI][cli]

端末でエージェント型アシスタントを使います。Plan と Autopilot モード、instructions、skills、カスタムエージェント、Playwright MCP、Agent Merge、実用的なスラッシュコマンドを使って作業します。

### [GitHub Copilot app][app]

並列エージェント セッションを実行し、セッション モードを切り替え、キャンバスで共同作業し、デスクトップ アプリで GitHub issue と pull request を管理します。

### [GitHub Copilot cloud agent][cloud]

GitHub issue を非同期エージェントに割り当て、その作業をガイドし、進捗を監視し、オープンした pull request を確認します。

### [Visual Studio Code][vscode]

Visual Studio Code と GitHub Codespaces で GitHub Copilot を使用します。Copilot Chat の agent mode、MCP サーバー、カスタムエージェントをエディターから離れることなく利用します。
