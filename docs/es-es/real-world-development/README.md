Explora GitHub Copilot a lo largo del ciclo de vida del desarrollo de software utilizando escenarios realistas, una aplicación completa y un backlog compartido. Trabajarás de forma iterativa para planificar cambios, crear código, probar comportamientos, revisar pull requests y gestionar el trabajo con agentes.

## Escenario

Eres un desarrollador nuevo en Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de mesa con temática de desarrollo. El backlog de tu equipo ya está registrado como incidencias de GitHub, listo para que las recojas. Incluye trabajo de funcionalidad, como filtrado y paginación, junto con mejoras de calidad como accesibilidad y estándares de codificación.

## Elige tu entorno

GitHub Copilot te acompaña donde trabajes. Elige el entorno que coincida con la forma en que quieres crear. Cada taller comienza con su propia configuración y utiliza el escenario compartido de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Usa el asistente basado en agentes en tu terminal. Trabaja con los modos Plan y Autopilot, instrucciones, habilidades, agentes personalizados, Playwright MCP, Agent Merge y comandos slash prácticos.

### [GitHub Copilot app][app]

Ejecuta sesiones de agentes en paralelo, cambia de modo de sesión, colabora en lienzos y gestiona incidencias y pull requests de GitHub en la aplicación de escritorio.

### [GitHub Copilot cloud agent][cloud]

Asigna incidencias de GitHub a un agente asíncrono, guía su trabajo, supervisa el progreso y revisa los pull requests que abre.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo de agente de Copilot Chat, servidores MCP y agentes personalizados sin salir de tu editor.
