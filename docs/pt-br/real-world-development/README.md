Explore o GitHub Copilot ao longo do ciclo de vida do desenvolvimento de software usando cenários realistas, um aplicativo completo e um backlog compartilhado. Você trabalhará de forma iterativa para planejar alterações, criar código, testar comportamentos, revisar pull requests e gerenciar o trabalho com agentes.

## Cenário

Você é um novo desenvolvedor na Tailspin Toys, uma empresa fictícia que oferece financiamento coletivo para jogos de tabuleiro com tema de desenvolvimento. O backlog da sua equipe já foi registrado como issues do GitHub, pronto para você começar. Ele inclui tarefas de funcionalidade, como filtragem e paginação, além de melhorias de qualidade, como acessibilidade e padrões de codificação.

## Escolha seu ambiente

O GitHub Copilot atende você em qualquer ambiente em que você trabalhe. Escolha o ambiente que combina com a forma como você deseja desenvolver. Cada workshop começa com sua própria configuração e usa o cenário compartilhado da Tailspin Toys.

### [GitHub Copilot CLI][cli]

Use o assistente em modo de agente no terminal. Trabalhe com os modos Plan e Autopilot, instruções, habilidades, agentes personalizados, Playwright MCP, Agent Merge e comandos práticos de terminal.

### [GitHub Copilot app][app]

Execute sessões paralelas de agentes, alterne os modos de sessão, colabore em telas e gerencie issues e pull requests do GitHub no aplicativo desktop.

### [GitHub Copilot cloud agent][cloud]

Atribua issues do GitHub a um agente assíncrono, oriente o trabalho, acompanhe o progresso e revise os pull requests que ele abrir.

### [Visual Studio Code][vscode]

Use o GitHub Copilot no Visual Studio Code e no GitHub Codespaces. Trabalhe com o modo de agente do Copilot Chat, servidores MCP e agentes personalizados sem sair do editor.
